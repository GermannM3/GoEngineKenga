# CyberNinja - 2D Платформер

Это полноценная 2D-игра, созданная на движке GoEngineKenga с использованием новой системы спрайтов. Игра включает в себя несколько уровней, полноценную физику, управление персонажем и красивую графику.

## Особенности

- 2D спрайтовая графика с использованием настоящих ассетов
- Физика и коллизии
- Управление персонажем (движение, прыжки)
- Камера, следящая за игроком
- Враги и предметы
- Несколько уровней
- Титульный экран

## Управление

- **A/D** или стрелки ←/→ — движение
- **Space/W/↑** — прыжок

## Структура проекта

```
CyberNinja/
├── project.kenga.json      # Конфигурация проекта
├── scenes/                 # Сцены игры
│   ├── title.scene.json    # Титульный экран
│   ├── main.scene.json     # Основной уровень (City Street)
│   └── level2.scene.json   # Второй уровень (Sewers)
├── assets/                 # Ассеты (текстуры, модели, звуки)
│   ├── backgrounds/        # Фоны уровней
│   ├── characters/         # Персонажи
│   │   ├── hero/           # Герой (кибер-ниндзя кенгуру)
│   │   ├── enemies/        # Враги (дроны, мехи, роботы)
│   │   ├── boss/           # Боссы
│   │   └── npc/            # NPC (наставник, торговец)
│   ├── items/              # Предметы и бонусы
│   └── ui/                 # Интерфейс
└── scripts/
    └── game/
        └── main.go         # Основной игровой скрипт
```

## Запуск

Для запуска проекта из корня движка:

```bash
# Титульный экран
go run ./cmd/kenga run --project CyberNinja --scene scenes/title.scene.json --backend ebiten

# Основной уровень
go run ./cmd/kenga run --project CyberNinja --scene scenes/main.scene.json --backend ebiten

# Второй уровень
go run ./cmd/kenga run --project CyberNinja --scene scenes/level2.scene.json --backend ebiten
```

## Игровые элементы

- **Герой**: Кибер-ниндзя кенгуру (использует hero_tpose_front.png)
- **Враги**:
  - Drone Scout (дрон-разведчик)
  - Mech Spider (механический паук)
  - Security Bot (охранник-бот)
- **NPC**: Mentor Koala (наставник-коала)
- **Предметы**: Sword, Power Up и другие
- **Фоны**: City Street, Sewers, Rooftop, Corporate HQ

## Технические детали

- Используется система ECS (Entity-Component-System)
- 2D рендеринг с автоматическим переключением
- Физика с гравитацией и коллизиями
- Система спрайтов с поддержкой слоёв и правильным позиционированием
- Камера, следящая за игроком с использованием FollowID
- Улучшенное позиционирование спрайтов с учётом их размеров
- Поддержка масштабирования и отражений
- Специальная система игровой логики для обработки взаимодействия
- Система обнаружения столкновений и определения нахождения на земле
- Система подбора предметов

## Игровая механика

- Управление персонажем: A/D или стрелки ←/→ для движения, Space/W/↑ для прыжка
- Физика с гравитацией и инерцией
- Система коллизий для определения нахождения на земле
- Камера, автоматически следящая за игроком
- Система подбора предметов при приближении
- Визуальная обратная связь для взаимодействия
- Система анимаций: автоматическое переключение между анимациями (idle, walk, jump, attack) в зависимости от действий игрока
- Анимации для врагов и NPC

- Специальную систему игровой логики для обработки игровых механик
