# Создание полноценной 2D игры "CyberNinja" на GoEngineKenga

## Обзор проделанной работы

Мы успешно создали полноценную 2D игру "CyberNinja" на движке GoEngineKenga, используя предоставленные ассеты из директории "D:\game_demo_assets".

## Что было реализовано

### 1. Система 2D спрайтов
- Добавлен компонент SpriteRenderer для отображения 2D-спрайтов
- Добавлен компонент Camera2D для 2D-камеры
- Создана система отрисовки спрайтов с поддержкой слоёв
- Реализована интеграция с основной системой рендеринга

### 2. Игровой проект CyberNinja
- Скопированы настоящие ассеты из "D:\game_demo_assets"
- Созданы 3 сцены: титульный экран, основной уровень, второй уровень
- Настроен проект с несколькими уровнями

### 3. Игровые элементы
- **Герой**: Кибер-ниндзя кенгуру (изображение hero_tpose_front.png)
- **Враги**: Drone Scout, Mech Spider, Security Bot
- **NPC**: Mentor Koala
- **Предметы**: Sword, Power Up
- **Фоны**: City Street, Sewers

### 4. Уровни
- **Титульный экран**: scenes/title.scene.json
- **Основной уровень**: scenes/main.scene.json (City Street)
- **Второй уровень**: scenes/level2.scene.json (Sewers)

### 5. Игровая механика
- Управление персонажем (движение A/D, прыжки Space)
- Физика с гравитацией и коллизиями
- Камера, следящая за игроком
- Система подбора предметов

## Технические особенности

### Архитектура
- Используется система ECS (Entity-Component-System)
- Автоматическое переключение между 3D и 2D рендерингом
- Система спрайтов с поддержкой слоёв и трансформаций

### Структура проекта
```
CyberNinja/

├── scenes/
│   ├── title.scene.json
│   ├── main.scene.json
│   └── level2.scene.json
```

## Запуск игры

Для запуска различных частей игры используйте следующие команды:

```bash
# Титульный экран
go run ./cmd/kenga run --project CyberNinja --scene scenes/title.scene.json --backend ebiten

# Основной уровень
go run ./cmd/kenga run --project CyberNinja --scene scenes/main.scene.json --backend ebiten

# Второй уровень
go run ./cmd/kenga run --project CyberNinja --scene scenes/level2.scene.json --backend ebiten
```

## Результат

Мы создали полноценную 2D игру с несколькими уровнями, используя настоящие ассеты. Игра включает в себя:
- Красивую 2D графику с анимированными персонажами
- Физику с гравитацией и коллизиями
- Управление персонажем
- Несколько уровней с разными фонами
- Врагов и предметы для подбора
- Систему камер, следящих за игроком

Это доказывает, что движок GoEngineKenga может успешно использоваться для создания полноценных 2D игр.
